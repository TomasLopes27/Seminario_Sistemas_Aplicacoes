# Preços de Combustíveis em Portugal: Padrões, Correlações e Fatores Explicativos

Projeto da unidade curricular **Seminário de Sistemas e Aplicações** — Mestrado em Engenharia Informática (UFP), 2026/2027.

## Estrutura
- `data/raw` — dados brutos (DGEG, FRED/EIA Brent, ISP)
- `data/processed` — dados limpos/consolidados
- `analysis` — scripts R (EDA) e figuras geradas
- `presentations` — apresentações Beamer (PDF) de cada Momento
- `docs` — ficha da unidade curricular (FUC)
